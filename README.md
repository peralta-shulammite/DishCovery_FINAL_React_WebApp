**🍽️ DishCovery**
AI-Powered Personalized Recipe Generator (Progressive Web App)
DishCovery is a Progressive Web Application (PWA) that helps users create safe, personalized recipes based on available ingredients and dietary restrictions. It is designed for individuals with allergies, intolerances, or specific dietary preferences by filtering unsafe ingredients and generating suitable meal recommendations.

**🚀 Features**

🔍 Ingredient Scanning – Scan ingredients using your device camera
🥗 Recipe Generation – Get personalized recipes based on selected ingredients
📦 Pantry Selection – Manually select ingredients from a categorized list
❤️ Favorites Management – Save and access preferred recipes anytime
👤 Profile Management – Store dietary restrictions and preferences
🔐 Secure Authentication – Account registration with email verification
📱 PWA Support – Install on mobile or desktop for app-like experience
🌐 System Requirements
Smartphone, tablet, or desktop computer
Android, iOS, Windows, or macOS
Recommended browser: Google Chrome
Stable internet connection

**🛠️ Tech Stack**
React.js – Frontend development
PyTorch – Ingredient recognition models
Google Colab – Cloud-based model training
Progressive Web App (PWA) architecture

**🔐 User Authentication**
**Sign Up**
Enter name and valid email
Create secure password (8+ characters, uppercase, lowercase, number)
Agree to Terms & Privacy
Verify email via verification code

**Sign In**
Enter registered email and password
Email verification is required before accessing the system.

**⚙️ Installation (PWA Setup)**
DishCovery can be installed as a Progressive Web App:
Open the app in Google Chrome
Click the Install App button
Confirm installation
Access DishCovery from your home screen

**👤 Initial Setup**
After registration, users must:
Select profile owner
Choose dietary restrictions (required)
Add optional ingredient exclusions
This ensures accurate and safe recipe recommendations.

**📷 Ingredient Input Methods**

**1️⃣ Ingredient Scanning**

Use device camera to scan ingredients
Automatic recognition
Manual correction available
Multiple scans per session supported

**2️⃣ Pantry Selection**

Browse ingredients by category
Select multiple items
Review and edit before generating recipes

**🥘 Recipe Generation & Management**

Generates recipes based on:
Selected ingredients
Dietary restrictions

Displays:
Ingredient list
Preparation instructions
Save recipes to Favorites
Access saved recipes anytime

**👤 Profile & Account Management**

Users can:
Update dietary preferences
View activity history (viewed recipes, saved recipes, scans)
Change password
Log out
Delete account (permanently removes data)

**🔒 Data & Privacy**

Secure account storage
Email verification for account activation
Permanent data deletion upon account removal

**📱 Cross-Platform Access**

DishCovery works on:
Mobile devices
Tablets
Desktop computers
Installable as a PWA without needing an app store download.
